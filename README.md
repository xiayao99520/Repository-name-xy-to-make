# gbro-collage-broll-jimeng

把中文口播变成可直接交给即梦的半自动 B-roll 素材包。

## 当前版本

- 用户只需提供：口播全文、要制作的口播句子、视频时长。
- 接受 4–8 秒：4 秒生成 2 张，4–6 秒生成 3 张，6–8 秒生成 4 张；例如 5 秒按 3 张处理。
- Codex 用内置生图生成 9:16 半调纸拼贴图片。
- 内置模板图只提供低权重风格参考，不复制模板中的具体物件和构图。
- 最终文件夹只包含编号图片和 `即梦视频提示词.txt`。
- 不调用 Gemini，不上传即梦，不生成剪映工程文件。

## 使用方式

在 Codex 中调用 `$gbro-collage-broll`，输入全文、目标口播和 4–8 秒时长。视觉隐喻、图片检查和提示词生成在内部完成，最终直接得到素材文件夹；把图片拖入即梦参考图区域，复制文本文件中的提示词生成视频。

本地整理脚本只负责复制已生成图片并写入提示词：

```powershell
python scripts/make_package.py `
  --transcript "完整口播全文" `
  --voiceover "要制作的口播句子" `
  --duration 5 `
  --scene "场景" `
  --objects "对象" `
  --action "动作" `
  --result "结果" `
  --image .\01.png --image .\02.png `
  --output .\output
```
