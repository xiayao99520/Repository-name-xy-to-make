## 直接造成漂移的差异

旧四图为研究桌 → 40克样本 → 肝脏下降数据 → 综合研究结果。构图、主要物件、比例和场景内容可变化，纸拼贴质感及题材配色一致。

新四图先放齐研究卡、肝脏、秤、刻度，然后依次加定量卡、加连接线、降低刻度。实际 prompt 四条均有 Fixed composition for all four stills 与相同坐标；后续有 add only、same board、no major relocation 等限制。

原始新日志第82、102、116行分别传 referenced_image_paths:[source1]、[source2]、[source3]；这已通过实际参数核实，证据不只来自助手说明或 manifest。旧初次四图为独立文生图，新版为连续改图链。

上一版 audited 主说明另加入“全片一个隐喻、3–6物件、先写所有图共用的元素位置和运动规格”，源自 GitHub 通用单完成静帧流程，却不是指定旧聊天实际半自动版的四图设计方式。这些强制要求现已撤回。

## 不冒充规则的历史问题

- 旧文档“Gate 2通过后再生图”与实际“Gate 1通过后生图”冲突，以真实执行纠正阶段措辞。
- 旧简介仍说即梦生图片，Codex补丁与实际调用已证明应为Codex；据实际调用修正。
- 旧票务的脚本结果写成拒绝退票，而实际第四图是挡板推开。保留历史文本在证据中，运行时按确认方案和图片结果整理。
- 旧抗性淀粉数值及标签的具体摆放不是任何新题材的通用规则；40克和57.7%的归属按口播保持，不能机械复制旧图可能含混的表达。
- 旧脚本提前生成04视频草稿、默认5秒确实存在。恢复代码保留这个行为，最终交付在图片确认后整理并以用户指定时长为准。
- 固定视角等旧视频描述不得反向施加为四张静帧同布局；也不凭此推断用户已在即梦实际生成视频。
- 未恢复模型隐藏推理、后端版本、随机种子，不能承诺像素相同。
